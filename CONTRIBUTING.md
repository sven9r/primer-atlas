# Contributing

Primer proposals start with the structured GitHub issue form. Include the marker,
both oligos in synthesized 5-prime to 3-prime orientation, claimed applications,
target taxa, expected product, and primary sources. Submissions are proposals,
not automatic catalog additions.

Curated changes require a pull request that updates the normalized catalog,
preserves original claim wording, declares coordinate or reference changes, and
passes all regression and release-gate tests. Large sequences and generated
scores belong in the configured object store, not Git.
