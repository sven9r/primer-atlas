# Code of conduct

Primer Atlas is a scientific collaboration. Contributors are expected to make
the project welcoming, rigorous, and useful across disciplines and experience
levels.

## Expected behavior

- Discuss evidence, methods, and code with respect and specificity.
- Credit sources and other contributors accurately.
- Welcome questions and explain project conventions without gatekeeping.
- State uncertainty, limitations, and conflicts of interest openly.
- Accept correction and review in the same spirit in which they are offered.
- Protect private information and unpublished contributor data.

## Unacceptable behavior

Harassment, discrimination, intimidation, personal attacks, deliberate
misrepresentation of evidence, unwanted disclosure of private information, and
retaliation against someone who raises a concern are not acceptable.

## Reporting and enforcement

For ordinary technical or scientific disagreements, use the relevant issue or
pull request. For sensitive conduct concerns, contact the repository owner
privately through the contact methods on the owner's GitHub profile. Do not
post confidential reports publicly.

The repository owner may edit or remove harmful content, restrict participation,
or remove access when necessary. Reports will be handled as privately and
promptly as practical, with attention to the safety of affected contributors.

This policy applies in the repository, project Discussions, issue trackers,
reviews, and other spaces where someone represents Primer Atlas.
